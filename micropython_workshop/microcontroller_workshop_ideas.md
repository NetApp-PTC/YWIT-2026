Ideas for 2026 microcontroller workshop
===

* Pocket DJ
  - A handheld digital insturment. Students program pitch frequencies, rhythm loops, and an LED pulse animation synchronized to the sound
  - https://www.amazon.com/Treedix-WS2812B-Individually-Addressable-Raspberry/dp/B09FSTT43H (3 segments per student)
  - push buttons
  - speaker

* Reflex Arcade
  - A reaction-time game. An LED lights up after a random delay; the user must press their button as fast as possible. Their reaction time is calculated and logged on the screen
  - push button
  - LED
  - oled

* Wi-Fi Mood Lamp
  - Write a local web server/app that displays a dashboard allowing control of LED lights
  - LEDs

* ESP-NOW Hot Potato
  - The workshop leader has a board that has special leader code and can start the game
  - Once the leader presses the start button, a timer starts couting down on a random one of the student's boards
  - The student must pass the potato to another random student by pressing a button
  - This preserves the remaning time and the next student has to pass again before the timer runs out
  - Once the timer hits 0, the student holding the potato "loses"

* Safe Cracker
  - Uses a rotary encoder with a built-in pushbutton
  - Turn the encoder clockwise and counter clockwise to try and match a secret sequence
  - The program gives you hints by playing a tone or sound effect when nearing and at the right number

* Tilting Ball Maze
  - Uses an MPU-6050 6-axis accelerometer gyro and an OLED screen
  - Draw a maze on the screen with a ball sprite
  - Tilting the board moves the ball around the maze
  - Try to get from the start to the finish
